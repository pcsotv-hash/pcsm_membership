# Color Palette

## Primary Palette (Preferred)
- Deep Green: `#0f5132` (primary backgrounds, headers)
- Accent Gold: `#b08a2e` (buttons, highlights)
- Cream: `#f9f5ea` (cards, subtle backgrounds)
- Text Dark: `#0f2a1f`
- Text Light: `#ffffff`

## Alternate Palette
- Navy: `#0b2e59`
- Accent Sand: `#c2a878`
- Off-white: `#f5f7fa`
- Text Dark: `#1a1a1a`
- Text Light: `#ffffff`

## Notes
- Buttons: large, rounded, icon + text; ensure contrast AA.
- QR: logo-embedded on deep green blocks; ensure scan contrast.
- Urdu RTL: check mirrored layout and typography legibility.
